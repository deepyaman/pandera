<objective>
Add the `native: bool` flag to `Check` and refactor all 14 narwhals builtin check function
signatures to match the new `(frame, key, ...)` calling convention.

Purpose: Establishes the flag and contracts that plan 02 uses to replace Dispatcher/annotation
detection in `apply()`. The builtins must be refactored before `apply()` is rewritten, because
plan 02's `native=False` path will call `check_fn(frame, key)` — the new signature.

Output: `Check` has `self.native`; all 14 builtins accept `(frame, key, ...)` instead of
`(data: NarwhalsData, ...)`.
